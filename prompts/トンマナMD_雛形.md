# 文体ルール（トンマナMD）
※記事を書く前に必ずこのファイルを全部読むこと
※これは雛形。各サイトのリポジトリにコピーし、差分学習で育てる

## 1. 基本の文体
- 一人称:「〇〇」（例: 私／僕）← サイトごとに決める
- 文末: です・ます調で統一
- NG語尾:「〜なんですよね」「〜だよね」（自分が使わない語尾をここに足していく）

## 1-2. 読みやすさのルール
- 一文は60字以下。読点「、」は1文に2個まで（3個必要なら文を分ける）
- 1段落は2〜4文
- 同じ語尾を3回続けない（「〜です。です。です。」は2回目で言い回しを変える）
- 体言止めは段落の締めに1回まで
- 漢字はひらく: 事→こと／時→とき／物→もの／下さい→ください／出来る→できる／是非→ぜひ／等→など／様々→さまざま
- 削れる言葉は削る:「〜という」「〜することができます」→「〜できます」
- あいまい語を数字にする:「たくさんの会社」→「3社」「かなり安く」→「15万円」
- 接続詞「そして」「また」を連発しない。なくても通じるなら消す
- 3つ以上並んだらリストにする

## 2. 文章の組み立て（PREP法）
- 結論を1文で言い切る → 理由 → 体験や数字 → 行動提案 の順
- 見出し直下の1文目は、そのセクションの結論を言い切る

## 3. AIのクセ禁止リスト
- 「ひとつずつご紹介しますね」のような情報量ゼロのつなぎ文を書かない
- 章末の「気の利いたまとめ文」を書かない（見出しの内容で完結させる）
- 装飾的な副詞を使わない:「ぐっと」「きっと」「大きく左右します」「非常に」
- 段落の主語を必ず書く。「1つ目は〜」「これで〜」だけの文は禁止
- 指示語（これ・それ・この）は文中で使わず、具体的な名詞で書く
- 「いかがでしたか」「ぜひ参考にしてください」を書かない

## 4. 語彙置換表（差分学習で育てる。最初は空でよい）
| AIが書きがち | 私ならこう書く |
|---|---|
| （例）お客さん | お客様 |
| | |

## 5. 体験談と数字のルール
- 体験談・数字は実在するものだけ。創作禁止。未計測の数値をAIが補完しない
- 体験は「不安だった → やってみた → 解消した」の流れで書く
- 体験が必要な箇所にまだ実体験がない場合は【体験追記】の印を残し、それらしい文で埋めない

## 6. 法令
- 「最強」「絶対」「間違いない」「No.1（根拠なし）」を使わない（景品表示法）
- 効果・安全を断定しない。「〜と感じました」「わが家では〜でした」の範囲で書く
- 記事冒頭のPR表記はテーマ機能で自動表示する場合、本文に重ねて書かない（サイトごとに確認）
