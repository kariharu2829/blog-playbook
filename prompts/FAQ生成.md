# FAQ生成の手順

本文が「本文GO」を経て完成したあとに実行する。目的は、記事の終盤に置くFAQ（よくある質問）を、**実際に読者が聞いている質問**から作ること。

## 手順
1. 次の情報源から、このKWに関する実際の質問を集める（AIが空想で質問を作るのは禁止）
   - ラッコキーワード「よくある質問検索」
   - ラッコキーワード「集客コンテンツ検索」（Yahoo!知恵袋に絞る）
   - サジェスト・関連キーワード（LSI/PAA）の疑問形
   - 上位10記事のFAQ見出し（見出し抽出）
   - 人が貼ったスクリーンショットやメモ
2. 集めた質問を、本文で答え済みのものと未回答のものに分ける
3. 未回答のものを優先し、3〜5問を選ぶ（5問以上あれば構造化データの効果が出やすい）
4. 各回答は2〜4文。結論を1文目に。本文と矛盾させない。体験・数字は実在するものだけ
5. 主力商品に自然につながる質問が1つあれば入れる（無理に入れない）

## 出力
- Q/A の一覧（Markdown）
- WordPressのFAQブロック用に整形したもの（テーマの形式に合わせる）
- 出典（どの情報源から拾った質問か）
