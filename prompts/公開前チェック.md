# 公開前チェックの手順

入稿が終わり、人が「公開前チェックして」と言ったら実行する。見つけた問題は一覧にし、「直しておいて」と言われたものだけ修正する。

## A. 機械的に見るもの（AIが全部やる）
- [ ] 誤字脱字の全文スキャン
- [ ] 表記揺れの統一（サービス名・商品名・単位・全角半角）
- [ ] リンク点検（内部リンクの遷移先、アフィリエイトリンクの置換漏れ、リンク切れ）
- [ ] 目次とページ内ジャンプの整合
- [ ] コピペ由来の不要タグ・空段落の掃除
- [ ] 画像のファイル名とalt属性
- [ ] タイトル32字以内、メインKW含有
- [ ] メタディスクリプション120字以内
- [ ] H2にサブKW含有
- [ ] FAQセクションが3問以上ある
- [ ] トンマナMDの禁止リストに当たる表現がない（一文60字超、禁止語尾、装飾副詞、指示語、章末まとめ文）
- [ ] 景表法に当たる表現がない（最強・絶対・No.1根拠なし）

## B. 人が判断するもの（AIは該当箇所を列挙するだけ）
- [ ] 【体験追記】の印が残っていない（残っていれば公開しない）
- [ ] 数字と体験がすべて実在する
- [ ] リード文が読者の検索意図に合っている
- [ ] 主力商品のCTAが、成果条件と一致した行動を勧めている
- [ ] 内部リンクが文脈に合っている（無理に貼っていない）
- [ ] 価格の根拠（確認日、為替注記）がある

## 出力
A・Bそれぞれの結果一覧。Bは該当箇所の引用つきで、判断は人に委ねる。
