# prompts/ — AIに渡すファイル

`steps/` は人が読む手順書。`prompts/` はその手順のうちAIに任せる部分を、そのまま読ませるファイルにしたもの。
記事ごとの層（ステップ3〜5）は毎回回すので、人が指示を打ち直さずに済むよう仕組み化する。

| ファイル | 使うステップ | 渡し方 |
|---|---|---|
| [記事構成リサーチ.md](記事構成リサーチ.md) | 3 | 「〇〇（KW）で記事構成を作って」と言う前に読ませる。スキル化してよい |
| [トンマナMD_雛形.md](トンマナMD_雛形.md) | 4 | **雛形。実体は各サイトのリポジトリにコピーして育てる**。執筆前に必ず全部読ませる |
| [FAQ生成.md](FAQ生成.md) | 4 | 本文ができたあと、FAQを作らせるときに読ませる |
| [公開前チェック.md](公開前チェック.md) | 4 | 入稿後、公開前に実行させる |
| [差分学習.md](差分学習.md) | 4の最後 | 自分で直し終えた原稿と初稿を渡して実行させる。トンマナMDが育つ |

原則:
- 数字・体験・引用は実データのみ。AIの推測で埋めさせない
- 構成の最終判断、リード文、商品紹介部分、公開の判断は人がやる。prompts/ はそこに踏み込まない
- チャットで注意しても次回に残らない。直したいことは必ずファイルに書く
