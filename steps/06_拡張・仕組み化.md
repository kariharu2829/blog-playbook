# ステップ6：拡張・仕組み化

状態: 確定（入口のみ。中身は着手時に実績を見て埋める）　　最終更新: 2026-09-11

このステップは意図的に薄い。月5万円を超えるまで手を出さない領域なので、「いつ・何をきっかけに着手するか」だけを決めておく。

## 目的
**月5万円を超えたあと、時間を増やさずに収益を伸ばす。**
それまでは、ステップ3〜5を回し続けることが最も収益に効く。

## 着手条件（両方揃うまで開かない）
- [ ] 確定報酬で月5万円を**3か月連続**で超えている
- [ ] ステップ5の月次サイクル（毎月1日の一覧更新、月3〜5本のリライト）が3か月以上回っている

条件を満たした日付をブログ創業計画書に記録してから始める。

## インプット
- ブログ創業計画書（実測で更新済みのもの）
- 記事一覧（ステップ5）：案件別の発生・確定、成約記事の流入
- トンマナMDと `prompts/`（外注の仕様書になる）
- お気に入りに寝かせてある新着案件（ステップ1のルーティン）

## 打ち手は4つ。この順番で検討する

### 1. 特単交渉（同じ記事で単価を上げる）
- 対象：月の確定件数が10件を超えた案件
- ASPの担当者に、実績（件数・確定率・流入KW）を添えて相談する。担当者がつかないASPなら、同じ案件を扱う他ASPの条件も見る
- 記事を増やさずに数式の「1件あたり報酬」が上がる。最初にやる理由はこれ

### 2. 外注化（AIに任せている工程の監督を人に渡す）
- 対象：初稿、入稿、公開前チェックA、FAQ、図解。**リード文・体験・セールス・構成の確定は渡さない**
- トンマナMD・`prompts/`・`structure.md` がそのまま発注仕様書になる。仕様書なしで発注しない
- 初稿生存率と同じ指標で外注の品質を測る
- 月の投下時間が上限に張りついてから。余裕があるうちは自分で回す

### 3. 横展開（もう1サイト）
- 対象：新着案件の4象限（ステップ1）で「KWが広がる × 既存と関連なし」に当たったもの
- ステップ0〜2をもう1サイト分やる。近道はない。創業計画書が埋まるまで開設しない
- 1サイト目のステップ5が止まらない範囲で。止まるなら時期が早い

### 4. SNS・メルマガ（検索以外の導線）
- 対象：成約記事に直接流す導線。検索順位に左右されない流入を持つ
- SEOが安定してから。先にやるとリライトの時間が食われる
- 記事から自動生成できる投稿（Xの複数パターン、Pinterest）はAIに任せる

## アウトプット
- ブログ創業計画書に「拡張フェーズ」の欄を追加：着手日、選んだ打ち手と理由、目標、見直し日
- 横展開なら新サイトの創業計画書（ステップ0〜2の成果物）

## 完了基準
- [ ] 着手条件2つを満たした日付が記録されている
- [ ] 4つのうちどれを先にやるか、理由つきで決めている
- [ ] 特単交渉なら、実績資料を添えて相談した記録がある
- [ ] 外注なら、仕様書（トンマナMD・prompts・structure）を渡し、品質指標を決めている
- [ ] 横展開なら、新サイトの創業計画書がステップ0〜2で埋まっている
- [ ] 1サイト目のステップ5が止まっていない

## よくある失敗
- **月5万円前に横展開する**：両方が育たない。1サイト目で型を体に入れてから
- **仕様書なしで外注する**：品質が崩れ、直す時間が自分で書くより長くなる
- **SNSに時間を取られてリライトが止まる**：検索流入の柱を先に固める
- **特単交渉を遠慮する**：件数があれば普通に通る。記事を1本も増やさず単価が上がる最も安い打ち手
- **拡張を「稼げていない不安」の逃げ場にする**：着手条件を満たしていないなら、やることはステップ3〜5
