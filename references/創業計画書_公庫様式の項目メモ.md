# ブログ創業計画書の元になった様式：日本政策金融公庫「創業計画書」（国民生活事業）

社長から共有された公庫の創業計画書（Excel様式）の項目構成と、ブログ創業計画書（`_template/ブログ創業計画書.xlsx`）への対応。
「取扱商品・客単価・売上」が空欄だと計画として成立しない構造を、そのまま「売る物を先に決める」の強制装置として使う。

## 公庫様式の10項目

| # | 項目 | 主な欄 |
|---|---|---|
| 1 | 創業の動機 | 目的・動機 |
| 2 | 経営者の略歴等 | 年月・内容（勤務先・担当業務・役職・技能）／過去の事業経験／取得資格／許認可／知的財産権 |
| 3 | 取扱商品・サービス | 事業内容／商品①②③と売上シェア／客単価／営業日数・定休日・営業時間／海外展開／セールスポイント（自社の強み）／販売ターゲット・販売戦略（集客方法）／競合・市場など自社を取り巻く状況 |
| 4 | 従業員 | 常勤役員・従業員数（うち家族・パート） |
| 5 | 取引先・取引関係等 | 販売先／仕入先／外注先（シェア・掛取引・回収支払条件）／人件費の支払 |
| 6 | 関連企業 | 経営している企業 |
| 7 | お借入の状況 | 借入先・使いみち・残高・年間返済額 |
| 8 | 必要な資金と調達方法 | 設備資金・運転資金（見積先・金額）／自己資金・親族借入・公庫・他行（金額・返済方法）／合計は一致 |
| 9 | 事業の見通し（月平均） | 創業当初／1年後又は軌道に乗った後：売上高①・売上原価②・経費③（人件費・家賃・支払利息・その他）・利益①－②－③／計算根拠 |
| 10 | 自由記述欄 | アピールポイント・悩み・希望するアドバイス |

## ブログ創業計画書への対応

| 公庫 | ブログでは | 埋めるステップ |
|---|---|---|
| 1 創業の動機 | 動機、目標月収（確定ベース）、期限、単価の型 | 0 |
| 2 経営者の略歴等 | 発信者の略歴と体験資産（職歴・技能・家庭の出来事・過去のブログ経験・資格）。「誰として語るか」＝E-E-A-Tの根拠 | 0 |
| 3 取扱商品・サービス | 事業内容（ジャンル・コンセプト）／主力①サブ②③（案件名・ASP・成果報酬・確定率・客単価＝報酬×確定率・成果条件・売上シェア）／セールスポイント＝自分だけの一次情報／販売戦略＝KWクラスタと導線／競合・市場＝M&A実データと上位サイトのDA・個人ブログの有無 | 1・2 |
| 4 従業員 | 体制：週の投下時間、外注予算、週あたり公開本数、AIに任せる工程・本人がやる工程 | 0 |
| 5 取引先 | 販売先＝ASP・広告主（提携状況・成果条件・確定率・支払サイト）／仕入先＝ツールとインフラ／外注先 | 1 |
| 6 関連企業 | 既存サイト・SNS・ドメインなどの既存資産 | 0 |
| 7 お借入の状況 | 毎月の固定費に置き換え（見通しの経費に流し込む） | 0 |
| 8 必要な資金と調達方法 | 初期費用（サーバー・ドメイン・テーマ・体験用の商品購入）と調達（自己資金）。差引を出す | 0 |
| 9 事業の見通し | 創業当初（公開3か月後）／12か月後：PV・遷移率・成約率・発生件数・確定率・確定件数・1件報酬・売上・経費・利益。根拠欄に「M&A実例／仮置き／実測」を書く | 0で仮置き、5で実測 |
| 10 自由記述 | 不安・リスク・欲しいアドバイス。創業計画書チャットに出すときの質問 | 0 |
