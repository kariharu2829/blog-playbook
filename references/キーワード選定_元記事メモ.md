# キーワード選定の参考メモ：「Google検索の1ページ目を狙うキーワードの決め方」（こーにゃん氏・第2弾）

ステップ「KW選定」の骨格として採用する外部ノウハウの要点。原文の転載ではなく要約。
出典: リベシティ ノウハウ図書館（2026-09 読み込み）

## 大前提
- 売る商品が決まっても、まだブログを開設しない。先にキーワード選定をする。ここに1週間かける
- 用語: **キーワード選定**＝どのKWで書くかを決める一連の流れ。**キーワード調査**＝その中で検索ボリューム・CPC・ライバルの強さを調べる工程
- 調査で集める判断材料は3つ: 検索ボリューム（どれだけ検索されるか）、CPC（収益が期待できるか）、ライバルの強さ（1ページ目に入れるか）。ライバルの強さはGoogleの検索結果がそのまま答え

## 9ステップ
1. ASPで売る商品を決める（第1弾）
2. 商標KWから関連KWリストを取得する。GetKeyword（無料・SMS認証で月40回）推奨、ラッコキーワード・Ubersuggestでも可。**絞らず丸ごと取る**。取れるのはKW・検索vol・CPC・競合性
3. KWリストから1つずつ、**シークレットモード**でGoogle検索する（履歴に左右されないフラットな結果を見る）
4. バーティカル検索の一番左のタブ（AIモード・すべてを除く）でクエリ判定。ショッピング=Buy、動画=Do、地図・旅行=Go、ニュース・書籍=Know、画像=結果で判断。**Know以外は成約に近いので優先**。ただし激戦
5. 上位10記事に個人ブログがあるか。ドメインで目星（.co.jp/.ac.jp/.go.jpは企業・学校・官公庁、.com/.net/.jpは個人の可能性）、運営者情報で確認。**1つでもあれば狙う価値あり**。なければ言い換えKW（日本語⇔英語・略語、漢字⇔かな、正式名称⇔通称、専門用語⇔日常語）で再検索
6. DA（Moz ドメインオーソリティ、Ubersuggest拡張で表示。無料は1日40回）で強さを見る。**20未満、好ましくは1桁なら個人でも可能性あり**。DA1桁で上位の記事には理由があるので中身を見る
7. スプレッドシートにまとめる。列: KW / 検索vol / CPC / 競合性 / 1〜10位DA / DA平均 / バーティカル検索 / クエリ判定 / 取得日。DA10未満と20未満で条件付き書式の色分け（10未満のルールを上に）
8. 似たKWをグループ化してカニバリ（自分の記事同士の共食い）を避ける
9. 優先順位を決める。目安: 検索vol100以上 ／ 1ページ目にDA20未満（好ましくは10未満）の個人ブログあり ／ 収益性が高い（CPCが高い、Know以外）。読者の悩み解決に必要なら基準外でも書く。カニバリさえ避ければ書かなくていいKWはない

## Q&A
- DAは日で多少上下するが1〜2の差で判断は変わらない。数か月前の数値は当てにならないので取得日を残す
- 個人ブログが1つもなければ上位表示は難しいが、書くべきKWなら他記事やSNSからの流入など別戦略。言い換えも試す
- **vol100未満は捨てない**。ライバルも少ない。優先順位の話であり、上位10記事のDAが低ければ狙える
- 検索結果はログイン状態や履歴で変わる。自分がよく見るサイトを「強い」と誤判定しないようシークレットモードで
- 商標でKWが枯渇したら「その商品を使う人の悩み」まで広げる。SNSの検索窓も使える（Instagramは投稿件数が需要の目安、X・Threadsは量と新しさ）
- 一部はAIに任せて効率化できるが、**1ページ目に入れるかを判断するのは自分の目**
