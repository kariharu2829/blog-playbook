# 案件選定の参考メモ：「ASPで売る商品の探し方」（こーにゃん氏）＋質疑応答

ステップ2（案件選定）の骨格として採用した外部ノウハウの要点。原文の転載ではなく要約。
出典: リベシティ ノウハウ図書館「ASPで『売る商品』の探し方」および同記事へのQ&A（2026-09）

## 大前提
- ブログで稼ぐために最初にやるのは「売る商品を決める」こと
- ブログを作ってから商品を探すのではなく、商品を見つけてからブログを作る
- 探す場所は A8.net。案件数が国内最大級、ブログのドメインがなくてもSNSアカウントで登録できる、EPC・確定率が載っている
- 他ASP（もしも・バリューコマース・afb・アクセストレード）は後からサブで見れば十分
- **A8.net の案件を1週間かけて全部見る。** ここだけはAIに任せず本人がやる。「自分の過去・現在・未来」と案件を照らし合わせる作業は本人にしかできない

## 6ステップ
1. **ライフスタイルを思い浮かべる**：過去にハマった物、現在身の回りにある物、将来欲しい物・ありたい姿。最優先は「現在の身の回り」（目視できて記憶が新鮮）
2. **成果報酬の高い順に見る**：3,000円以上、好ましくは5,000円以上。数を売るより単価で目標に届くほうが達成しやすい
3. **成果条件は購買ハードルが低いものを狙う**：成果条件＝成果地点との距離。報酬と成果条件はシーソー（近いほど報酬は低い）。例: 資料請求 → 電話相談 → 入会。報酬が下がりすぎない範囲で成果地点の近いものを選ぶ
4. **EPCは70以上、好ましくは100以上。ただし盲信しない**：EPC＝過去30日の発生報酬 ÷ クリック数。新着はデータ不足で出ない、高報酬・成約に近い条件ほど高く出やすい、半年で半分以下になることもある
5. **確定率は60%以上、好ましくは80%以上**：確定率＝確定件数 ÷ 発生件数。報酬5,000円×2件でも確定率50%なら期待5,000円。成果地点が近い案件ほど否認が少なく確定率が高くなりやすい
6. **お気に入り登録してから決める**：一覧化はその後でよい（AIのブラウザ操作で可）。1商品または1商品群に特化して「〇〇といえばこのブログ」を狙う。特化はE-E-A-Tを高める

4指標は単独で見ず相互作用で見る。優先順位は **成果報酬 ＞ 成果条件 ＞ EPC ＞ 確定率**。

## ルーティン
- 新着プログラムのチェックを習慣にする（新着順に並び替え、カテゴリを問わず見る）
- 新着＝市場調査。ライバルが少なく先行者利益を狙える
- 可能なら A8.net 以外のASPも見て市場調査の幅を広げる

## Q&A（記事内）
- 1週間かける価値はある。ブログは数年運営するもので、土台に1週間は最も安い投資
- ブログがなくてもSNSアカウントで登録して閲覧できる。ブログがない今こそ始めどき
- 見つからないとき：お気に入りを2周目で見返す／新着を毎日見る／自分の過去をもっと深く掘る
- 使ったことがない商品でも、後から体験して書けるなら扱ってよい
- 向かない人：自社商品を売りたい人、自己表現が目的の人、物販（Amazon・楽天）で稼ぐ人
- AIに「稼げる商品は？」と聞いても全員に同じ答えが返る。自分の経験と案件を照らし合わせる作業だけは本人にしかできない

## 質疑応答で得た追加知見

### EPC・確定率が「ー」の案件
- 「ー」＝データ不足であって、案件が悪い意味ではない。「ー」だけを理由に外さない
- 判断は優先順位に戻る。成果報酬と成果条件で判断できるなら進めてよい（ただしEPCが低いと分かっている案件をあえて選ぶことはしない）
- 「掲載が古いのに『ー』のまま」は、提携者が少ない（ライバルも少ない）のか、売れていないのか、外からは分からない。**成果条件で推測する**

| 成果条件 | 「ー」の解釈 | 扱い |
|---|---|---|
| 資料請求・無料登録（成果地点が近い） | まだ知られていないだけの可能性 | 見る価値あり |
| 購入・有料契約（成果地点が遠い） | 売りにくい可能性 | 優先順位を下げる |

- 一発で判断できないので「保留にして他の案件と比べる」扱いがちょうどいい
- あわせてキーワードの検索ボリュームと見比べ、勝ち筋があるかを先に見る

### 新着で良い案件を見つけたとき、新ドメインか既存ブログか
2軸で決める。「その商品のキーワードがどれだけ広がるか」「既存ブログと関連があるか」。

| | 既存ブログと関連あり | 関連なし |
|---|---|---|
| KWが広がる | どちらもあり。既存に足して育ててから切り出す手も | 新ドメインで特化 |
| KWが少ない | 既存ブログに1本書いてみる | 保留。お気に入りのまま寝かせる |

- KWの広がりは実際に洗い出して検索ボリュームを見る。商標KWだけなら1〜2記事で終わる規模。関連KWが次々出るならブログが1つ成り立つ規模
- 「1商品群に特化＝新ドメイン」が成り立つのは、書くKWが十分にあるときだけ。サイトを育てる手間を考えると先にここを確かめる価値がある
- 「いま動かない」も判断のひとつ。書く場所もKWもない状態で始めると記事が増えずドメインも育たない
